# ⛽ TenderGuard: Пальне

Аналізатор ризиків у державних закупівлях **пального** на відкритих даних **Prozorro**.

Програма бере завершені закупівлі бензину, дизелю та газу, визначає вид пального за назвою товару,
порівнює ціну за літр з нормою для того самого виду пального, перевіряє кожну закупівлю
за 5 прозорими правилами, рахує **Risk Score (0–100)** і пояснює, чому закупівля потрапила до списку.

> Бал показує кількість ризикових ознак. Це привід перевірити закупівлю, а не доказ порушення.

## Дані
- Джерело: [Prozorro Public API](https://public-api.prozorro.gov.ua/api/2.5/tenders), відкриті дані.
- `data/fuel.jsonl`: усі закупівлі пального (CPV 0913…, 09122…) серед ~10 000 останніх завершених
  конкурентних закупівель, без контактних даних.
- Ціна за літр береться з пропозиції переможця, окремо для кожного товару.
- Як отримано дані: `python -m tenderguard.prozorro_api 10000` — переглядає 10 000 останніх завершених
  закупівель і зберігає лише пальне (у нас вийшло 1258 з 10 063). Займає ~20 хвилин.
  Якщо файлу `data/fuel.jsonl` немає, програма при запуску завантажить його сама, і це теж довго.

## Як шукаємо переплату
1. Вид пального: точний код CPV, якщо він є (09134… дизель, 09133… газ), інакше — текст опису:
   «Дизельне паливо (Євро 5), талон» → Дизель; також А-95, А-92, Газ.
2. Ціна за літр — з пропозиції переможця, окремо для кожного товару, без ПДВ.
   Якщо цін по рядках немає, але пальне в закупівлі одного виду, — сума договору / усі літри.
3. **Справедлива ціна** = медіана ціни за літр у закупівлях **з реальною конкуренцією (3+ учасники)**
   того самого виду пального і того самого обсягу (до 2 тис. л, 2–10 тис. л, понад 10 тис. л).
   Якщо таких закупівель замало — усі обсяги; для газу й А-92 (конкурентних майже немає) — усі закупівлі.
   Чому так: без конкуренції пальне типово на ~3.4% дорожче, а великі закупівлі дешевші за малі.
4. **Переплата** = (ціна − справедлива ціна) × літри, якщо ціна вища більш ніж на 5%.
5. Не аналізуємо (чесно порівняти неможливо): «бензин» без марки; кілька видів пального однією сумою;
   однакові рядки без цін (незрозуміло, скільки літрів насправді); пальне, якого замало для порівняння (А-98);
   ціни, вдвічі вищі чи нижчі за медіану свого пального (помилки в даних). Лишається 1085 закупівель із 1258.
6. З областю не порівнюємо замовників без вказаної області (переважно військові).

## Правила Risk Score (0–100)
| Правило | Бали |
|---|---|
| Ціна вища за справедливу: плавно, 0 до +5%, максимум від +20% | до 40 |
| Лише один учасник | 25 |
| Імітація конкуренції: учасників ≥ 2, а ціна впала < 1% від очікуваної | 15 |
| Той самий постачальник виграв у замовника ≥ 3 рази | 10 |
| Ціна на 10%+ вища за медіану цього пального в області | 10 |

## Структура
```
tenderguard/prozorro_api.py  завантаження закупівель пального з API Prozorro
tenderguard/loader.py        JSON → таблиці pandas (закупівлі і товари)
tenderguard/prices.py        вид пального, ціна за літр, справедлива ціна, переплата
tenderguard/rules.py         правила Risk Score і пояснення
tenderguard/pipeline.py      усі кроки аналізу разом
tenderguard/charts.py        графіки plotly
app.py                       дашборд Streamlit
tests/                       тести (pytest)
```

## Запуск
```bash
pip install -r requirements.txt
streamlit run app.py
pytest
```
